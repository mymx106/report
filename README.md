# 교육 만족도 결과보고서 생성기

만족도 설문 CSV를 올리고 기본 정보를 입력하면, 기존 결과보고서 양식 그대로의 **PPT 파일**을 만들어 주는 웹페이지입니다.

**HTML 파일 하나가 전부입니다.** 스타일, 스크립트, PPT 생성 라이브러리, 삽화까지 모두 그 안에 들어 있어
어디에 올려도, 심지어 더블클릭으로 열어도 그대로 동작합니다. 서버도 설치도 필요 없습니다.

설문 문항 코드가 다른 두 가지 CSV 형식이 있어 파일도 두 개입니다. **나머지는 완전히 같습니다.**

| 파일 | CSV 형식 |
|---|---|
| `index.html` | **A형** — 점수 문항이 `P1B2`부터 시작하고 중간에 비점수 문항이 끼어 번호가 띄엄띄엄, 주관식 `P1B23` |
| `index-b.html` | **B형** — 점수 문항 15개가 `P1B1`부터 빈 번호 없이 연속, 주관식 `P1B16` |

어느 쪽 파일인지는 화면 맨 위 제목 옆에 표시됩니다.

## GitHub Pages로 올리기

두 파일 모두 저장소 최상단에 올리면 됩니다. `index.html`이 기본으로 열리고,
B형은 주소 뒤에 `/index-b.html`을 붙이면 됩니다.

```bash
git remote add origin https://github.com/<계정>/<저장소>.git
git branch -M main
git push -u origin main
```

저장소 **Settings → Pages → Source: Deploy from a branch → main / (root)** 으로 두면
`https://<계정>.github.io/<저장소>/` 에서 바로 열립니다.

## 쓰는 법

1. **기업명 / 교육명 / 로고** 입력 — 표지(1P)와 2P부터 마지막 장까지 우측 상단 로고에 자동 반영됩니다.
   로고는 원본 비율 그대로 들어가므로 찌그러지지 않습니다.
2. **교육 개요** 입력 — 교육일정(차수별 표), 교육인원(1~10차수), 교육목표, 교육시간, 강사(1~10차수).
   인원·강사는 **값을 적은 차수까지만** 슬라이드에 들어갑니다.
3. **CSV 업로드** — 점수가 집계되고 분석 문구가 자동으로 작성됩니다. 문구는 그 자리에서 고칠 수 있습니다.
4. **사진 첨부** — 교육사진 6장(9P), 출석부 2장(10P).
5. **결과보고서 PPT 생성** 버튼 → `[결과보고서] 기업명_교육명.pptx` 다운로드.

## 만들어지는 슬라이드

| 장 | 내용 | 출처 |
|---|---|---|
| 1P | 표지 (기업명 / 교육명 / 로고) | 입력 |
| 2P | 평가 문항 표 (고정) + `기업명_교육명 : 과정에 대한 설문 문항은…` | 고정 + 입력 |
| 3P | 교육 개요 (과정명·일정·인원·목표·시간·강사) | 입력 |
| 4P | 종합만족도 그래프 (전체 평균 + 항목별 평균) + 분석 | CSV |
| 5~7P | 세부 만족도 — 한 장에 그래프 2개 + 각각의 분석 | CSV |
| 8P | 주관식 의견 (A형 P1B23 / B형 P1B16) — 한 장에 12개씩 | CSV |
| 9P | 교육사진 6장 | 첨부 |
| 10P | 출석부 2장 | 첨부 |
| 11P | Thank You + 로고 | 입력 |

## CSV 형식

설문 원본 CSV를 그대로 넣으면 됩니다. `P1B2`, `P1B3` … 같은 **문항 코드가 들어있는 행**을 자동으로 찾아
그 아래 응답 행만 집계하므로, 제목 행·문항 텍스트 행·척도 행이 앞에 몇 줄 있어도 상관없습니다.

| 항목 | 세부 문항 | A형 (`index.html`) | B형 (`index-b.html`) |
|---|---|---|---|
| 과정 만족도 | 전반적 만족도 · 추천도 | P1B2 · P1B3 | P1B1 · P1B2 |
| 학습 목표 만족도 | 목표제시 · 달성도 · 이해도 | P1B5 · P1B6 · P1B7 | P1B3 · P1B4 · P1B5 |
| 과정 구성 만족도 | 교재구성 · 시간구성 | P1B9 · P1B10 | P1B6 · P1B7 |
| 교육환경 만족도 | 환경만족도 · 운영만족도 | P1B13 · P1B14 | P1B8 · P1B9 |
| 강사 만족도 | 체계성 · 기법활용 · 참여유도 · 전문성 | P1B16 ~ P1B19 | P1B10 ~ P1B13 |
| 현업 실천도 | 업무수행기여도 · 현업활용도 | P1B21 · P1B22 | P1B14 · P1B15 |
| 주관식 의견 | — | P1B23 | P1B16 |

- 항목 평균 = 그 항목에 속한 문항 평균들의 평균
- 전체 평균 = 여섯 항목 평균의 평균
- A형의 `P1B11`(시간 구성 저점 사유)처럼 매핑에 없는 열은 집계에서 빠집니다.

## 고치고 싶을 때

`index.html`과 `index-b.html`은 자동으로 만들어지는 파일이라 직접 고치지 마시고,
`src/` 안의 원본을 고친 뒤 다시 빌드하세요. 한 번 돌리면 두 파일이 같이 갱신됩니다.

```
src/index.html                입력 폼
src/style.css                 화면 스타일
src/app.js                    CSV 집계 · 분석 문구 · PPT 생성 (두 형식 공용)
src/codes-a.js                A형 문항 코드 매핑
src/codes-b.js                B형 문항 코드 매핑
src/assets/*.png              표지·주관식 페이지 삽화 (양식 원본)
src/vendor/pptxgen.bundle.js  PptxGenJS 3.12.0
build.py                      위 파일들을 index.html / index-b.html 로 묶는 스크립트
```

```bash
python build.py
```

- 문항 코드를 바꾸려면 `src/codes-a.js` / `src/codes-b.js`
- 형식을 더 추가하려면 코드 파일을 하나 더 만들고 `build.py`의 `VARIANTS`에 줄을 추가
- 항목 이름·순서를 바꾸려면 `src/app.js`의 `CATS` 배열
- 색상·글꼴은 같은 파일 맨 위의 `T` 객체 (원본 양식 PPT에서 추출한 값)
- 각 슬라이드의 좌표는 `build()` 안에 장별로 나뉘어 있습니다

> 글꼴은 양식과 같은 **나눔바른고딕**을 지정합니다. PC에 이 글꼴이 없으면 PowerPoint가 기본 글꼴로
> 대체해 보여 주므로, 양식 그대로 보려면 나눔바른고딕을 설치해 두는 편이 좋습니다.
